# 研究室 用語ライブラリ

研究室の活動で学んだ用語を、用語・解説・タグ・参考リンクの単位で閲覧する静的HTMLアプリです。

## 構成

- `index.html`: コマンドなしで開ける閲覧画面
- `.styles.css`: 画面スタイル用の隠しCSSファイル
- `app.js`: JSON読み込み、検索、タグ絞り込み、ページ内追加、ライト/ダーク切替
- `terms.json`: WebDAV共有用の用語データ

## 起動

普段の閲覧は`index.html`をダブルクリックして開けます。コマンドは不要です。

```text
index.html
```

`index.html`を直接開いた場合は、内蔵の用語データを表示します。
WebDAV上で開いた場合は、同じフォルダの`terms.json`を表示します。

## WebDAV共有

WebDAV形式の研究室サーバに置く場合は、次の4ファイルを同じフォルダにアップロードします。

```text
index.html
.styles.css
app.js
terms.json
```

WebDAV上のURLで`index.html`を開くと、同じフォルダの`terms.json`を優先して読み込みます。
サーバがブラウザからの`PUT`保存を許可している場合、「追加」タブから登録した用語は`terms.json`へ保存され、他の利用者にも共有されます。
保存が許可されていない場合は、自動的にブラウザ保存へ切り替わります。

## ページ内追加

ローカルで`index.html`を直接開いた場合、「追加」タブから登録した用語はブラウザの`localStorage`に保存され、内蔵データと一緒に表示されます。
追加した用語は詳細画面の「追加データを削除」から削除できます。
WebDAV上で`terms.json`保存に成功した用語は共有データになるため、別端末でも表示されます。

## データ更新

WebDAV上で使う場合は、「追加」タブから登録すると`terms.json`へ保存されます。
手作業で編集する場合は、`terms.json`をテキストエディタで開いてJSONを編集してください。
